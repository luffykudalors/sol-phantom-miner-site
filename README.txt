SOL PHANTOM MINER — PWA PROTOTYPE

This is a mobile-friendly Progressive Web App prototype, not a crypto miner.
No live tasks, verified rewards, accounts, or real SOL payouts are connected.
Task submissions and the optional public wallet address are stored locally in this browser.

FILES: index.html, manifest.webmanifest, sw.js, icon.svg

UPDATE YOUR GITHUB PAGES SITE
1. Open https://github.com/luffykudalors/sol-phantom-miner-site
2. Tap Add file > Upload files.
3. Upload all FOUR files from this ZIP, replacing index.html if asked.
4. Commit changes to main.
5. Wait a minute and reload https://luffykudalors.github.io/sol-phantom-miner-site/

INSTALL ON ANDROID
Open the site in Chrome > three-dot menu > Install app or Add to Home screen > confirm.
Wording varies by device/browser.

BEFORE REAL REWARDS
- Static GitHub Pages cannot securely verify partner conversions or protect reward balances.
- Add a backend with authentication, database rules, server-side postback verification, anti-fraud
  checks, audit logs and admin review.
- Apply to a legitimate task provider with accurate site details. Some providers require a custom
  domain, real traffic and app/site review.
- Never put private keys, seed phrases or secret API keys in the app/site.
- Test transfers on Solana Devnet first. Devnet SOL is not real money.
