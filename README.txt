SOL Phantom Miner — website starter

Files:
- index.html: responsive, static project website.

Free hosting with GitHub Pages (from Android):
1. Sign in or create a GitHub account at https://github.com/
2. Create a new public repository named sol-phantom-miner-site.
3. Upload index.html to the repository root (use Add file > Upload files).
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment. GitHub will show the public Pages URL in Settings > Pages.

Use the actual URL shown by GitHub. Do not claim the app has live rewards or payouts until those features exist. Hosting does not guarantee publisher approval.
